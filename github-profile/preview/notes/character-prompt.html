从人物设定到四视图提示词

查看 Skill · 完整文字示例

这份记录说明 guoman-character-designer 的提示词组织方法。引用的是仓库已有文字示例，尚未附上对应生成图或模型对比结果。

输入与输出

示例输入是“一位62岁的古代女将军，花白头发，威严，穿深青色战甲”。

输出是一整段中文生图提示词，将这句话展开为角色气质、面部年龄特征、发型和服装层次，再规定四个视图的排列与一致性要求。完整输出可通过上方链接查看。

规则怎样组织

固定部分规定画面形式，采用 3D 半写实国漫与 BJD 式 CG 质感，纯白背景，左侧面部特写，右侧正面、侧面和背面全身。

可变部分跟随人物设定。示例保留花白头发、面部细纹与成熟体态，并把深青色战甲写到胸甲、肩甲和护裙之间的连接。角色年龄与身份需要同时体现在脸部、身体和衣着中。

跨视图约束把同一人物的发色、服装和配饰保持一致。示例中的长剑固定在左腰，鞋履需要完整入镜。这些是写入提示词的要求，实际生图是否遵守仍需逐张检查。

检查方法

仓库提供了六组 手动验收输入，覆盖年龄、性别和世界观变化。

检查先看文字是否保留人物信息，是否写明视图、服装与约束，再检查负面提示是否误伤角色特征。例如老年角色需要保留皱纹，带疤角色不能同时要求避免疤痕。

这些文件定义了检查方法，不代表六组用例已经全部执行通过。

下一步验证

选定生成模型与参数，用同一组人物输入完成小样本生图，保留输入、提示词、图片和失败记录。重点观察年龄表达、跨视图人物一致性，以及配饰位置是否符合要求。
