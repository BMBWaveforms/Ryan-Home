## 页面方向

延续现有网站的字体、导航、留白与编辑式排版。以 Workflow 的「左侧章节导航、右侧自由叙述」为正文骨架，结合项目详情页的标题与项目信息。首版沿用 About 的深色背景。

页面由内容决定篇幅，不要求每个项目填写同一组模块，也不要求每节配图。正文以段落自然展开，少用卡片、数据格和机械编号。章节标题可以因项目调整。

## 阅读路径

入口：Work 项目卡片、About 黑客松卡片或直接链接。

银河漫游现已替换 Work 的 Project 03，占据同一项目槽位，归入 Game / Video。Visual 整卡、Text 整行与 About 卡片使用同一详情地址；项目详情属于 Work，底部主返回入口回到项目列表。

进入页面 → 项目标题与简述 → 左侧章节导航和正文 → 项目收尾 → 返回来源页面。

标题区包含项目名称、一句话介绍及少量信息：时间、类型、个人角色；奖项等重要结果可直接展示。无需强制设置通栏封面，不额外增加重复介绍。

正文进入阅读区域后，桌面端左侧导航保持可见，右侧内容自然纵向滚动。左侧约占四分之一，右侧约占四分之三；文字保持较窄行宽，图片可使用右侧的全部宽度。

《银河漫游》可先使用这些章节：

- 关于银河漫游：作品是什么、核心体验与本次参赛背景。
- 从想法到体验：围绕实际做出的产品讲设计与实现，并写清个人贡献；主题数量和篇幅由材料决定。
- 72 小时现场：团队协作、现场演示与冠军／最佳人气奖，配少量精选现场照片。

这些是本项目的内容提纲，不作为所有项目固定栏目。需要时再从正文中拆出独立章节。

## 组件与交互

### 章节导航

- 数据：章节 ID、短名称及顺序，必须与实际正文对应。
- 点击滚动到相应章节，标题不被顶部导航遮挡。
- 随阅读位置更新当前章节强调；状态同时通过颜色与线条或字重区分。
- 支持章节链接直达与刷新；减少动态效果偏好下直接定位。
- 窄屏改为正文顶部的横向章节导航，保证内容宽度，不保留左侧栏。
- 使用真实锚点链接，支持键盘操作并保留清晰焦点。

### 自由正文

- 可组合小标题、段落、简短职责说明、单图、图片组和视频。
- 文字与图片允许交替出现，不为对齐而强制统一每节高度。
- 重要判断可通过一句大字或局部强调呈现，避免重复总结。
- 展示团队成果时写明个人负责范围；原型、完成成果与后续规划按事实措辞。

### 图片轨道

- 单图正常展示；多图进入同一条横向图片轨道，控制页面纵向长度。
- 精选代表图片，避免相近照片重复展示。无需自动播放轮播。
- 露出下一张的一部分，让横向可浏览的方式清晰可见。
- 支持触摸滑动、触控板横向滚动及前后按钮；正文垂直滚动不被劫持。
- 照片保持自然比例，必要时使用留白；产品截图以内容可读为优先。
- 每张图片可带简短说明；需要看细节时点击放大，Esc 关闭并归还焦点。
- 一张图片时隐藏翻页控件，多张时提供当前位置提示。
- 图片加载前保留尺寸，加载失败时保留说明与重试入口。

### 页面收尾

- 根据内容可放一段复盘、团队分工或实际可访问的项目链接，不强制全部出现。
- 返回入口回到来源卡片位置；直接进入详情页时提供返回 Work 的入口。
- 仅在确有其他项目时显示相关项目或下一个项目。
